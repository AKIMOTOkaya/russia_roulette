# 客户端

这里存放面向玩家的客户端。各客户端可以采用不同语言和框架，但必须使用统一协议，只展示 `PlayerView` 并提交命令。

当前实现的客户端包括：

- `web/`：零构建单页 Web 客户端，面向局域网或公网真人在浏览器中参与对局。
- `astrbot_plugin_russian_roulette/`：AstrBot 聊天机器人插件（独立 Git 仓库），作为对局主持人与展示端，使 QQ/IM 用户可通过 `/指令` 直接参与游戏，通过 MCP 协议与后端游戏引擎通信。因需独立上架插件商城，该目录被根仓库 `.gitignore` 忽略并自成独立 Git 仓库。
- 桌面端等其他形态在后续产品路线明确后再建立。

# 文档目录

- `rules/`：权威玩法语义和裁定规则；[本地 Web MVP 规则](rules/local-web-mvp-rules.md)记录当前实现切片。
- `architecture/`：系统边界、进程、源码模块与部署架构；当前代码抽象见[本地 Web MVP 架构](architecture/local-web-mvp-design.md)。
- `development/`：面向具体产品支线的实施路径；当前入口是[本地 Web MVP 开发与运行](development/local-web-mvp.md)。
- `project/`：持续维护的项目说明、仓库结构、模块边界、命名与流程。
- `development-log/`：按开发会话记录的变更、决策、验证与遗留事项。

Markdown 是持续维护的源稿；DOCX 是供阅读和评审的阶段性导出版本。规则或架构发生变更时先修改 Markdown，在里程碑或正式评审前重新导出 DOCX。

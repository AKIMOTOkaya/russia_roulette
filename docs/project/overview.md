# 项目概览

## 产品定位

《俄罗斯轮盘》（暂定名）是一款多人、多端、权威规则驱动的回合制轻游戏。项目从“QQ 群 + 主持 Bot”的文字玩法起步，计划逐步支持 Web、桌面、CLI、聊天平台适配器与 AI 玩家。

## 当前优先路线

当前优先交付本地 Web MVP：浏览器提供页面与交互，本机 `roulette-backend` 承载唯一权威对局和随机 Bot。先完成可玩的确定性 Core + Host 纵向切片，再恢复公网多人、房间和持久化路线。

## 核心原则

- 所有客户端只提交意图，不直接修改权威状态。
- `roulette-core` 先产生可重放的结构化结果，模板或 LLM 只负责叙事表达。
- 相同规则版本、状态、命令和显式随机状态应产生相同结果。
- Rust 负责领域、规则、Host 与首版服务端；客户端和工具允许采用合适的其他语言。
- 模块按职责和依赖方向拆分，不按“看起来整齐”提前拆成大量空包。

## 当前完成度

- 规则、总体架构、本地 MVP 规则与公网版开发路径已形成分层文档。
- Rust 工作区已实现本地 MVP 所需的 Domain、Core、Host 和 HTTP 组合入口。
- 原生 Web 客户端已可完成单人对随机 Bot 的本地对局。
- 已建立与服务器 `~/srv/apps/roulette` 对应的部署模板；当前仅连接 Caddy 使用的 `srv_edge` 网络。
- 本地 HTTP 层选用 Axum；公网 Web 框架、数据库访问层与协议生成工具尚未冻结。
- MVP 概率和地形白名单已经作为试作值落地，仍需游戏平衡验证，不能视为最终规则。
- 数据库尚未接入；待确认数据库角色、库名和迁移方式后再加入共享 `srv_data` 网络。

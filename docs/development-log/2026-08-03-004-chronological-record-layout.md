# 开发日志：记录时间线顺序与行为归类

- 日期：2026-08-03
- 会话：004
- 状态：完成
- Git：与本日志同一提交；提交信息 `fix: make game records chronological`

## 用户目标

修正全局记录从下往上、从右往左的阅读问题，改成自上而下的单列时间线；确保机器人行为归类为行动而不是事件。

## 范围与假设

- 时间线以 sequence 从小到大显示，最早记录在上，最新记录在下。
- 记录更新后自动滚动到最新位置，用户仍可向上查看历史。
- 世界状态变化仍可引用相关玩家，但玩家或 Bot 的命令本身只属于行动。

## 关键决定

- 移除前端的数组反转和双列布局。
- 移除重复的 `ShotFired` 世界事件；射击只写一次行动，空膛、未命中、命中等另写事件。
- 将事件文案改为位置变化、路径受阻、枪膛状态和弹道结果，避免把玩家行为描述成事件。

## 修改内容

- 调整 Web 时间线排序、自动滚动、单列布局和事件文案。
- 从 Domain 与 Core 删除 `ShotFired` 事件及其生成逻辑。
- 同步项目说明、模块说明、MVP 规则和架构文档。

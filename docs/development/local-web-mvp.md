# 本地 Web MVP 开发与运行

## 当前成果

本地版已形成可运行的纵向切片：创建一局、生成地图、玩家行动、自动机器人回合、结构化事件、胜负结算和重开。它用于尽早验证玩法与抽象，不代表公网协议或视觉设计已冻结。

## 运行

需要 Rust 1.97 或兼容的 stable 工具链。在仓库根目录执行：

```bash
cargo run -p roulette-backend
```

浏览器打开 <http://127.0.0.1:8787>。可使用环境变量 `ROULETTE_HTTP_HOST` 和 `ROULETTE_HTTP_PORT` 修改监听地址；本地开发默认只绑定回环地址。

## 操作

- 地图旁的紧凑操作区：空间足够时与地图同框显示，窄屏时移到地图下方。
- 方向按钮：按当前界面模式移动或射击；键盘方向键始终移动。
- `Shift + 方向键`：射击。
- 空格：等待一回合。
- “结束自己”：立即出局。
- 输入相同随机种子，可以配合相同操作序列复现问题。
- “对局时间线”统一显示行动、事件、回合和通知；它们按发生顺序排列，但不表示固定因果关系。

## 开发验证

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace
```

改变 Domain JSON 结构时还应启动服务，至少通过一次浏览器开局和行动流程。当前前端无包管理器或构建步骤，修改 `clients/web` 后重新编译/运行后端即可更新嵌入资源。
